# فرمت آماده‌سازی دادهٔ تجهیزات (برای بارگذاری در BASPAR CMMS)

این سند دقیقاً مشخص می‌کند داده را با چه فرمتی آماده کنید تا موتور «مرکز شارژ داده» بدون خطا وارد کند.
دو فرمت پشتیبانی می‌شود. **فرمت A (تک‌شیت)** ساده‌ترین و پیشنهادی است.

---

## فرمت A — تک شیت، یک ردیف per تجهیز (پیشنهادی)

یک شیت به نام `تجهیزات` با سرستون‌های زیر (ردیف اول = هدر). هر تجهیز یک ردیف:

| ستون | الزامی | توضیح / مقادیر مجاز |
|---|---|---|
| کد تجهیز | ✔ | یکتا. پیشوند کارخانه + حوزه (§7) مثل `B1PT-001` |
| نام تجهیز | ✔ | نام فارسی تجهیز |
| کارخانه | – | اگر خالی، از پیشوند کد استنتاج می‌شود |
| دسته | – | مثل: ماشین‌آلات تولید، تأسیسات، برق، ترابری، فوم، انبارش، برش، اسفنج |
| زیرسیستم | – | نام زیرسیستم (اختیاری) |
| قطعه | – | نام قطعه (اختیاری) |
| سازنده / مدل / شماره سریال / سال ساخت | – | اختیاری |
| وضعیت | – | `فعال` / `غیرفعال` / `در دست تعمیر` / `اسقاط` |
| درجه اهمیت | – | `A`=بحرانی `B`=زیاد `C`=متوسط `D`=کم (یا کلمات کم/متوسط/زیاد/بحرانی) |
| سالن / بخش / خط / موقعیت | – | اختیاری (محل استقرار) |
| تاریخ نصب | – | شمسی `1404/05/26` یا میلادی `2025-08-17` |
| درجه اتوماسیون | – | `دستی` / `نیمه اتوماتیک` / `اتوماتیک` |

نمونه: `data/templates/equipment-single-sheet.xlsx`

---

## فرمت B — چند شیت، هر شیت = یک تجهیز (مثل فایل فعلی شما)

هر شیت نامش = کد تجهیز، و داخلش یک جدول با سرستون‌های زیر است (یک ردیف داده):
`کد تجهیز، نام تجهیز، دسته، قسمت، محل تجهیز، تاریخ نصب، درجه اتوماسیون، وضعیت تجهیز، درجه اهمیت`
نمونه: `data/templates/equipment-multi-sheet.xlsx`

## پیشوندهای کارخانه (§7) — برای استنتاج خودکار
`B1`بسپار۱ `B2`بسپار۲ `B3`بسپار۳ `B4`بسپار۴ `BT`ترابری `FA`فوم مامونیه

## نکات
- شیت‌های اضافی با نام/هدر «مشخصات فنی / برنامه نگهداری / سوابق تعمیرات / قطعات» به‌صورت خودکار به‌عنوان دادهٔ تکمیلی همان تجهیز وارد می‌شوند.
- کدهای تکراری = Conflict (خودکار ادغام نمی‌شود؛ شما تصمیم می‌گیرید).
- پیشوند ناشناخته = نگه‌داشته می‌شود تا Admin تعریف کند (حدس زده نمی‌شود).
