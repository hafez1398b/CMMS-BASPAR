# ماتریس مسئولیت‌های نت و پرسنل — بسپار

> منبع: حافظ بایرامیان (مسئول نت، مدیر فنی، طراح سامانه) — ۱۴۰۴
> این سند مرجع نهایی برای انتساب دستورکارها و سوابق نگهداری است.

## ۱. تیم فنی و مهندسی کارخانه فوم

| نام | تخصص | توضیح |
|---|---|---|
| محمود محمود آبادی | تأسیسات | |
| اصغر رضایی | جوشکاری / تأسیسات | |
| محسن پیرایش | مکانیک خودرو و صنعتی | |
| احمد کاووسی | برق صنعتی | **تمام برق صنعتی همه کارخانجات (حتی بسپار۱)** |
| سجاد شکری | کارگر فنی | |
| حافظ بایرامیان | مسئول نت / مدیر فنی / طراح سامانه | کنترل، تأیید و ثبت نهایی |

### محدوده کار تیم فوم
* تجهیزات **همه دسته‌ها** به‌جز دسته «ماشین‌آلات تولید».
* دسته‌های عمرانی، ایمنی و پشتیبانی و سایر دسته‌ها: **با تیم فنی فوم**.
* موارد برون‌سپاری/خارج از حیطه تیم: سیستم برقی ماشین‌آلات (توسط کاووسی انجام می‌شود)،
  تعویض روغن گیربکس کانوایرها، تعویض کاسه نمد بعضی پمپ‌ها.
* تجهیزات دسته «ماشین‌آلات»: توسط تیم فوم چک **نمی‌شوند**، اما توسط
  **حافظ بایرامیان (مسئول نت)** کنترل، تأیید و در سامانه ثبت می‌شوند.

## ۲. نفرات فنی بسپار۱ (برای ثبت سوابق ماشین‌آلات)

| نام | نقش | مسئولیت |
|---|---|---|
| مهندس علی جهان مرادی | مدیر تولید | درخواست‌دهنده و تأییدکننده فعالیت‌ها |
| نجات بابایی | مکانیک صنعتی | اجرای تعمیرات مکانیکی |
| پوریا معافی پور | مکانیک صنعتی / تأسیسات | اجرای تعمیرات مکانیکی و تأسیساتی |
| عزت شاه کرمی | جوشکار | جوشکاری + مسئول انبار مواد اولیه فوم |

## ۳. قواعد انتساب رکوردها در سامانه

1. کارهای **برق صنعتی در هر کارخانه‌ای** ← تکنسین: `a.kavousi` (احمد کاووسی).
2. سوابق ماشین‌آلات **بسپار۱** (مثل دستگاه تزریق) ← تکنسین‌های بسپار۱
   (`n.babaei`, `p.moafipour`, `e.shahkarami`)؛ درخواست/تأیید: `a.jahanmoradi`.
3. سوابق ماشین‌آلات **کارخانه فوم** ← ثبت و تأیید توسط `h.bayramian`
   (اجرا توسط تیم فوم نیست).
4. سایر دسته‌ها در **فوم** ← متناسب با تخصص: تأسیسات `m.mahmoudabadi`/`a.rezaei`،
   مکانیک `m.pirayesh`، برق `a.kavousi`، کمک‌فنی `s.shokri`.
5. هر رکورد تاریخی که با عنوان کلی «تیم فنی و مهندسی» آمده باشد، باید پیش از ثبت
   به یکی از نفرات بالا انتساب یابد (تأیید نهایی با مسئول نت).
6. **قاعده زمانی (دستگاه تزریق و سایر ماشین‌آلات بسپار۱):**
   * دستورکارها و سوابق **تا قبل از برج ۱۰ سال ۱۴۰۴** ← بر اساس قاعده کلی
     تکنسین‌های بسپار۱ (معمولاً نجات بابایی، مگر آنکه در فایل نام دیگری باشد).
   * دستورکارها و سوابق **از برج ۱۰ سال ۱۴۰۴ (دی‌ماه) به بعد** ← تکنسین:
     **پوریا معافی پور** (`p.moafipour`).
   * بازه میلادی معادل برج ۱۰ ۱۴۰۴: از ۲۰۲۵-۱۲-۲۲ (دی) به بعد.
   * مبنا برای تشخیص، تاریخ دستورکار/سابقه است نه تاریخ ثبت در سامانه.
