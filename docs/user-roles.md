# نقش‌ها و دسترسی کاربران (§36, §38)

## نقش‌های فعال فاز ۰
| نقش | شرح | دسترسی کلیدی |
|---|---|---|
| **admin** (مدیر سیستم/Designer) | پیکربندی سامانه، کاربران، نقش‌ها، داده پایه، ممیزی، پشتیبان | همه دسترسی‌ها (§38) |
| **technical_manager** (مدیر فنی) | مدیریت تجهیزات و برنامه‌های نت، ورود گروهی، مشاهده کاربران/ممیزی | equipment.*, plans.*, import.manage |
| **technician** (تکنسین) | مشاهده تجهیزات و برنامه‌ها (در فاز ۱: اجرای دستورکار آفلاین) | equipment.view, plans.view |
| **viewer** (بازدیدکننده) | فقط مشاهده | *.view محدود |

## نقش‌های آماده برای فاز ۱+
maintenance_manager، supervisor، warehouse، requester — ساخته‌شده در Seed تا RBAC بدون تغییر Schema توسعه یابد.

## مدل دسترسی
دسترسی‌ها کدهای `module.action` هستند (view/create/edit/delete/approve/export/manage). ماتریس نقش‌ها در UI «نقش‌ها و دسترسی‌ها» توسط Admin قابل ویرایش است و هر تغییر در گزارش ممیزی ثبت می‌شود.
